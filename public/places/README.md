# Place photos

Drop your images here using these exact filenames — the globe in section 05
picks them up automatically, no code change needed.

| File | Place |
|------|-------|
| `an-giang.jpg` | An Giang — hometown |
| `ho-chi-minh.jpg` | Ho Chi Minh City — living here |
| `ha-noi.jpg` | Hà Nội — capital |
| `south-korea.jpg` | Seoul, South Korea — visited |
| `malaysia.jpg` | Kuala Lumpur, Malaysia — visited |

The card is 3:2, so landscape crops around 1200×800 look best. Anything
missing falls back to an initials plate, so the section is never broken.

To add, rename or reorder places, edit `src/data/places.ts`.
